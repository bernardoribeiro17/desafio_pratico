Código Exemplo

Como usar CSS Variables:

/* Use as variáveis CSS disponíveis no seu CSS/SCSS */
.elemento {
  background-color: var(--color-primary);
  color: var(--color-text);
  border-color: var(--color-border);
}

/* As cores mudam automaticamente ao trocar de tema */

Como chamar temas via JavaScript:

// Definir tema específico
theme.set('default')  // tema azul/laranja
theme.set('dark')     // tema escuro
theme.set('green')    // tema verde

// Alternar para próximo tema
theme.toggle()

// Verificar tema atual
const currentTheme = localStorage.getItem('tech-store-theme')
